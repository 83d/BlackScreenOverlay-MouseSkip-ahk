# BlackScreenOverlay-MouseSkip-ahk

在 Windows 双屏桌面中，用黑色窗口遮住副屏左侧区域，并让鼠标双向跳过该区域。脚本使用 AutoHotkey v2，适合主屏在左、副屏在右的布局。

## 当前脚本

| 文件 | 配置 |
| --- | --- |
| [screen2-left-800px.ahk](./screen2-left-800px.ahk) | 副屏左侧 800px 黑色遮罩，鼠标双向跳过 |

目前只提供 800px 版本，其他宽度的脚本后续按需添加。

## 工作方式

```text
┌───────────────┐ ┌───────────────┬─────────────────┐
│     主屏      │ │ 副屏左侧黑区  │ 副屏可见区域    │
│               │ │     800px     │                 │
└───────────────┘ └───────────────┴─────────────────┘
               ────── 向右跳过 ──────→
               ←───── 向左跳过 ──────
```

- 从左侧跨入黑区，鼠标跳到黑区右侧。
- 从右侧跨入黑区，鼠标跳到黑区左侧。
- 跳转只修改 X 坐标，传入的 Y 坐标保持不变。
- 黑色遮罩覆盖目标显示器左侧的整个高度。

脚本通过定时检查鼠标位置实现跳转，不是硬件级鼠标屏障。黑框只是覆盖内容，不会改变显示器分辨率或应用窗口布局。

## 使用条件

- Windows 11。
- 已安装 [AutoHotkey v2](https://www.autohotkey.com/)，不支持 v1。
- 至少两块显示器，使用扩展桌面模式。
- 当前版本按“最靠右的非主显示器”选择目标，不按 Windows 显示设置中的编号强制选择显示器 2。
- 目标副屏宽度应大于 800px；主屏应紧邻副屏左侧，且需要穿越的位置处于两屏共有的高度范围内。否则黑区左侧可能没有有效屏幕坐标，Windows 可能会限制或调整鼠标落点。

## 启动与退出

1. 下载 `screen2-left-800px.ahk`。
2. 双击脚本运行，副屏左侧会出现黑框。
3. 分别从左右两侧移入黑区，检查双向跳转效果。
4. 按 `Ctrl + Alt + F12` 退出，也可以通过 AutoHotkey 托盘图标选择 Exit。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + F11` | 显示或隐藏黑色遮罩；鼠标跳转仍然启用 |
| `Ctrl + Alt + F12` | 退出脚本，关闭遮罩与鼠标跳转 |

脚本不会写入注册表、安装驱动或修改显示器配置。退出后，遮罩消失，脚本不再干预鼠标移动。

## 配置

可在脚本开头修改以下参数，保存后重新运行：

```ahk
deadZoneWidth := 800  ; 黑区宽度，按物理像素设计
showBlack := true    ; 启动时显示遮罩；false 表示仅启用鼠标跳转
```

当前文件名对应 800px 配置。重新运行同一路径的脚本会替换原实例；如果复制或改名后运行，请先退出旧脚本，避免多个实例同时干预鼠标。

## 当前限制

- 修改显示器排列、分辨率或缩放后，需要重新运行脚本以读取新的边界。
- 跳转依赖前一次采样的 X 坐标判断进入方向。鼠标启动时已经在黑区中，或从黑区上方、下方进入时，当前逻辑可能无法将其移出。
- 定时采样存在延迟，不能保证每一帧都看不到黑区内的指针。
- 遮罩为置顶且点击穿透的普通窗口，不会阻止所有方式对下层应用的操作，也不保证覆盖独占全屏应用或系统安全桌面。
- 不同缩放、显示器布局和全屏应用下的效果需要实际验证。
